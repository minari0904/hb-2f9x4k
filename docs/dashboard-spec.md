# `index.html` 내부 구조

단일 파일. 외부 스크립트·폰트·CDN을 쓰지 않는다. 차트는 직접 그린 SVG.

---

## 1. 설정 (`CONFIG`)

```js
const CONFIG = {
  mode: 'encrypted',   // 'csv' = 시트 CSV 직접 읽기(개발용) | 'encrypted' = data.enc 복호화(배포용)
  csvUrl: '',          // mode:'csv'일 때 대시보드데이터 게시 CSV. 비우면 ./data.csv
  detailCsvUrl: '',    // mode:'csv'일 때 지출가계부 게시 CSV. 비우면 ./detail.csv
  encPath: 'data.enc'
};
```

**배포본은 반드시 `mode: 'encrypted'`.** 개발 중 `'csv'`로 바꿨다면 커밋 전에 되돌린다.
`csvUrl`에 실제 주소를 적은 채로 커밋하면 시트 주소가 공개된다.

## 2. 데이터 흐름

```
boot()
 ├ mode:'encrypted' → loadEncrypted()  비밀번호 입력 → PBKDF2(250k, SHA-256) → AES-GCM 복호화
 └ mode:'csv'       → fetch(csvUrl) + fetch(detailCsvUrl), 실패 시 내장 스냅샷(#fallback-csv)
      ↓  두 CSV를 "\n#=====DETAIL=====\n" 로 이어 붙인 하나의 텍스트
 parseCSV()      따옴표·줄바꿈 처리하는 자체 파서
 splitBlocks()   A열 '#마커' 기준으로 블록 분할 → {header, rows, objs}
 parseDetail()   지출가계부 원본을 월×항목별 거래 목록으로 재구성
 scanErrors()    모든 블록에서 #REF! 등 오류 문자열 탐지 → D.errors
 build()         → D = {meta, assets, pl, reasons, metrics, roadmap, snaps, port, goals, detail, errors}
 render()        전부 문자열로 조립해 #app.innerHTML에 넣고, draw()로 SVG를 그린다
```

**렌더는 통짜 재생성이다.** 필터를 바꾸면 `render()`가 다시 돈다.
펼침 상태는 `S.open`에 저장해 유지한다.

## 3. 상태 `S`

| 키 | 뜻 |
|---|---|
| `m` | 기준월 (1–12) |
| `owner` | `'all'` / `'꿀꿀'` / `'말벌'` |
| `pension` | `'in'` 연금 포함 / `'ex'` 제외 |
| `plTab` | `'flow'` 돈의 흐름 / `'pl'` 손익계산서 / `'bud'` 예산 대비 |
| `snapTab` | `'총자산'` / `'순자산'` / `'총부채'` |
| `allG`,`allK`,`allDir` | 전체 항목 표의 구분 필터 / 정렬 키 / 방향 |
| `open` | `<details>` 펼침 상태 |

## 4. 주요 함수

| 함수 | 역할 |
|---|---|
| `fmt(v)` | 금액 축약. `5.84억원` / `7,928만원` / `1,234원` |
| `full(v)` | 정확한 금액. 숫자를 탭하면 뜨는 값 |
| `dcls(구분,증감)` / `dspan()` | 증감 색. **"좋은 방향 = 초록"** (소비·부채는 줄면 초록) |
| `rateOK(r)` | 증감률이 ±999%를 넘으면 표시하지 않음 |
| `hStack()` | 가로 스택 막대 (2px 간격, 4px 둥근 끝) |
| `lineChart()` | 선 그래프 + 크로스헤어 툴팁, y축 눈금 자동 반올림 |
| `spark()` | KPI 카드 미니 그래프 + 호버 툴팁 |
| `colStack()` | 세로 막대. `colors[]`를 주면 카테고리별 색 지정 |
| `errBanner()` | 시트 오류 경고 박스 |
| `detailFor()`/`detailHTML()` | 손익 항목 클릭 시 펼쳐지는 거래 내역 |

## 5. 화면 구성

1. 헤더 — 제목 · 기준월 · 갱신일시 · 밝기 토글
2. 필터 한 줄 — 기준월 드롭다운 / 가구·개인 / 연금 포함·제외
3. **경고 박스** (오류가 있을 때만)
4. KPI 4장 — 순자산 · 투자자산 · 연금자산 · 로드맵 달성률
5. 우리 집 재산 — 자산 구성 스택 + 순자산/부채 + 순자산 흐름 선그래프
6. 이번 달 돈 — 돈의 흐름 / 손익계산서 / 예산 대비 (탭)
7. 이번 달 특이사항 — 사유가 적힌 항목만 카드로 + 전체 항목 표(필터·정렬)
8. 10년 로드맵 — 올해 진행률 + 10개년 목표 표 + 연도별 궤적
9. 포트폴리오 — 목표 대비 실제 비중
10. 연도별 추이 — 총자산 / 순자산 / 부채 탭

## 6. 디자인 규칙 (바꾸기 전에 `dataviz` 스킬을 읽을 것)

### 색
CSS 변수로만 쓴다. 라이트/다크 두 벌이 `:root`, `@media (prefers-color-scheme: dark)`,
`:root[data-theme="dark"]` 세 군데에 정의돼 있다. **세 군데를 같이 고쳐야 한다.**

| 역할 | 라이트 | 다크 |
|---|---|---|
| `--s1` 파랑 | `#2a78d6` | `#3987e5` |
| `--s2` 주황 | `#eb6834` | `#d95926` |
| `--s3` 청록 | `#1baf7a` | `#199e70` |
| `--s4` 노랑 | `#eda100` | `#c98500` |
| `--s5` 자홍 | `#e87ba4` | `#d55181` |

연도별 추이의 명도 단계(`--ord-a*` 파랑 / `--ord-n*` 초록 / `--ord-d*` 주황)는
대비 검증(ordinal ramp)을 통과한 값이다. 임의로 바꾸지 않는다.

자산 스택 순서·색: 부동산(s1) → 투자자산(s2) → 연금자산(s3) → 현금성(s4) → 청약저축(s5).
돈의 흐름: 변동소비(s1) → 고정소비(s2) → 대출상환(s3) → 저축·투자(s4) → 남은 돈(s5).
**인접한 슬롯끼리 색맹 대비를 검증한 순서라 순서를 섞으면 안 된다.**

### 그 밖
- 금액은 항상 `억원`/`만원`으로 끝난다. 숫자를 누르면 정확한 원 단위.
- 막대는 얇게, 격자선은 실선 1px, 점선 금지.
- 시리즈가 2개 이상이면 범례를 반드시 둔다. 모든 점에 숫자를 붙이지 않는다.
- 모바일 우선(세로 1열) → 760px부터 가로 배치.
- 차트를 고치면 **실제로 렌더해서 눈으로 확인한다.** 라벨 겹침·잘림은 검증기가 못 잡는다.

### 브라우저 저장소
`localStorage` 등을 쓰지 않는다. 밝기 토글도 세션 안에서만 유지된다.

## 7. 로컬에서 보기

```bash
python -m http.server 8899
```

`index.html` 사본을 만들어 `mode`를 `'csv'`로 바꾸고 같은 폴더에 `data.csv`(대시보드데이터)와
`detail.csv`(지출가계부)를 두면 시트 없이도 렌더된다.
스크린샷으로 확인하려면 Playwright(Chromium)로 `--viewport 430x900`,
라이트/다크 두 번 찍어 본다.
