## 요청할 때 잘 통하는 습관

- **증상을 그대로 붙여넣는다.** "숫자가 이상해"보다 "9월 투자자산이 3,000만원인데 7,000만원이어야 해"(예시 숫자)가 훨씬 빠르다.
- **화면을 캡처해서 준다.** 레이아웃 문제는 말로 설명하기 어렵다.
- **"확인까지 해줘"를 붙인다.** 고쳤다는 말만 믿지 말고 스크린샷이나 수치 검산을 요구한다.
- **한 번에 하나씩.** 여러 개를 한꺼번에 시키면 어느 게 문제인지 찾기 어려워진다.
- 시트 값을 직접 보게 하려면 **구글 드라이브 연동**을 켜두면 된다. 켜져 있으면
  "시트 읽어서 확인해줘"가 그냥 통한다.
